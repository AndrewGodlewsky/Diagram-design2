Inside the output-check loop

One local Python process reads the generated HTML and collects rule violations. The agent owns the repair loop; the checker owns the loops over files, tags, references, SVGs, points, scripts, and motion items.

B / INSIDE verify(path) — CHECKS RUN IN THIS ORDER

Read once, collect a structured inventory

Path.read_text(encoding="utf-8") → DiagramParser(HTMLParser). Parser callbacks visit tags, attributes, and text; collect SVG records, IDs, references, CSS, scripts, and motion metadata.

Start the shared findings list

errors = [] → append unsafe markup found while parsing: disallowed embedded elements, on… event attributes, and srcdoc. Each subsequent check appends more findings. The source is reparsed for tag balance and geometry.

CHECK → WHAT IT INSPECTSTOOLS → INNER LOOPBOUNDARY OF THE CHECK
01

Document completeness

check_document_completeness

Requires a closing HTML shell; flags U+FFFD replacement characters and unequal counts of selected opening / closing tags.

HTMLParser + Counter + re

Trim trailing comments; scan the document again; iterate the selected paired tag names.

Tag-count agreement is not full HTML validation.
02

CSS reference rules

check_css_references

Decodes CSS escapes; rejects @import, non-fragment url(), image-set(), and other detected remote references.

re · string scanning

Combine style blocks + CSS-valued attributes; iterate CSS URL matches.

Static string checks; no CSS engine or stylesheet download.
03

HTML / SVG references

reference_error + --offline

Checks collected src, href, srcset and related attributes. Allows the exact Google Fonts HTTPS /css2 endpoint for stylesheet links.

urllib.parse.urlparse

For every collected reference: append an error if forbidden. Offline mode also rejects the approved font link.

Offline mode adds a rule; it does not isolate the network.
04

Accessible SVG structure

check_svgs

Requires role=img, a first-child title, nonempty title + desc, prefixed naming IDs, and the exact aria-labelledby order.

Parsed records + Counter

For each nondecorative top-level SVG: check its fields and naming-ID counts.

Validates markup requirements, not a screen-reader experience.
05

Static viewBox bounds

check_viewbox

Collects coordinates for supported shapes and text anchors. Flags the worst overshoot on each edge when it exceeds 2 units.

HTMLParser + numeric arithmetic

Reparse → each SVG → each collected point → left, top, right, bottom. Keep the maximum excess per edge.

Skips unsupported / dynamic geometry. Does not measure glyph widths, SVG paths, stroke paint, or browser pixels.
06

JavaScript controller

check_scripts

Allows at most one script, with the exact control attribute and the canonical template-motion.html controller body.

String comparison + HTMLParser

For each script: check closure and attributes; read/parse the canonical template and compare normalized text.

Normalizes line endings and outer whitespace. Never executes the script.
07

Motion contract, if present

check_motion

Checks root/mode, up to 8 semantic steps and 12 items, contiguous step IDs, labels, controls, status, and fallback markup.

Sets + Counter + re

Return immediately without motion. Otherwise iterate items, compare step sets/counts, and check required controls.

Checks structure and fallback declarations; does not play the animation.

Result collection: ordinary rule failures accumulate in errors; the pipeline continues to later checks. The CLI prints FAIL file plus each finding, or OK file, and moves to the next input. Read / decoding errors become failures; unexpected exceptions can abort the run.

C / DEEPER REPOSITORY CHECKS — SEPARATE COMMANDS

Source & geometry gates

lint-skin.py, verify-geometry.py, and verify-motion.py add repository-level style, connector, and motion checks. These are not called by self_check.py.

Rendered checks: Playwright + Chromium

lint-render.py opens HTML in a browser. It compares screenshots before / after releasing clipping. Its loops cover SVGs, clipping ancestors, and capture scales. It also checks overflow and runtime errors; network is blocked by default.

Type checks & CI

Type-specific Python verifiers recompute supported chart / structural claims. GitHub Actions runs the repository gate suite. The agent must separately invoke applicable checks for a newly generated file.

What “OK” means: these implemented checks found no violation. The installed checker has no browser, AI model, third-party dependency, file-repair action, or network isolation. It does not prove visual correctness or complete security; the earlier audit demonstrated redirect and SVG-animation gaps.

          failed = True
          print FAIL and each error
      else:

  exit(1 if failed else 0)
