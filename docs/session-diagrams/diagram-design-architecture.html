How Diagram Design works

The AI agent makes the design decisions. The skill supplies the rules and templates; local Python helpers parse, check, and export the result.

Where the intelligence lives

The host AI model interprets the request and authors the layout. The skill has no model server of its own. Importers parse data without running Mermaid or Excalidraw renderers.

Where the network enters

Your AI provider processes the agent session. Optional website onboarding uses host browsing tools. Normal templates load Google Fonts; system-font mode removes that dependency.

Development tools, separate from use

GitHub Actions runs repository checks. Pillow builds README thumbnails. Neither is needed for ordinary diagram generation; Playwright is needed for PNG export.
